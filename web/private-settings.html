Usuários e permissões

Você é o administrador. Libere acesso apenas para contas autorizadas a ver os chamados. O cadastro não envia convite nem altera a rede Tailscale.

Colaboradores não acessam configuração, exportações, mídia ou mensagens brutas. Para instalar no celular, abra Chamados e use o menu do navegador para adicionar à tela inicial.
